CheckLinks

Utilitaire en ligne de commande en Zig pour vérifier les liens d'une page web : il télécharge la page, collecte tous les liens (<a href>) et images (<img src>), puis vérifie la disponibilité de chaque URL.

Télécharger la version Dépôt GitHub

Fonctionnalités

  • Chargement des pages via http://, https:// et file://
  • Extraction des URLs depuis href des balises <a> et src des <img>
  • Normalisation des liens relatifs et suppression des doublons
  • Vérification concurrente par HEAD par lots (5 requêtes parallèles par défaut)
  • Client HTTP HEAD intégré avec TLS et délai d'attente configurable (15 secondes par défaut)
  • En-têtes HTTP personnalisés et répétables pour les pages protégées
  • Tableau de résultats en couleurs : 2xx — vert, 3xx — jaune, 4xx/5xx — rouge
  • Export des résultats en CSV (séparateur ;)
  • Mode « erreurs uniquement » (--fail) et barre de progression
  • Interface en russe, anglais, espagnol ou français
  • Génération de scripts d'auto-complétion pour bash, zsh, fish et nushell
  • Sortie adaptée à la largeur du terminal (POSIX ioctl / API Windows)

Installation et compilation

Depuis les sources

Nécessite Zig 0.17.0 ou plus récent.

git clone https://github.com/kvt/check-links.zig
cd check-links.zig
zig build

Le binaire sera disponible dans zig-out/bin/check-links.

Utilisation

# Vérifier tous les liens d'une page et afficher le tableau
check-links https://example.com/

# Afficher uniquement les liens en erreur
check-links --fail https://example.com/

# Augmenter le délai d'attente et le nombre de requêtes parallèles
check-links --timeout 60 --parallels 20 https://example.com/

# Exporter les résultats dans un fichier CSV
check-links --export result.csv https://example.com/

Exemple de sortie

 №      | URL                     | URL vérifiée               | Code HTTP
     1. | https://example.com     | https://example.com/page1  |   200
     2. | https://example.com     | https://example.com/page2  |   200
     3. | https://example.com     | https://example.com/page3  |   302
     4. | https://example.com     | https://example.com/page4  |   404

Les codes 2xx sont affichés en vert, 3xx en jaune et 4xx/5xx en rouge.
