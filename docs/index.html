CheckLinks

Консольная утилита на языке Zig для проверки ссылок на веб-странице: загружает страницу, собирает все ссылки () и изображения () и проверяет каждый URL на доступность.

Скачать релиз GitHub-репозиторий

Возможности

  • Загрузка страниц по схемам http://, https:// и file://
  • Извлечение URL из href тегов и src тегов
  • Нормализация относительных ссылок и удаление дубликатов
  • Конкурентная проверка методом HEAD партиями (по умолчанию 5 параллельных запросов)
  • Собственный HTTP HEAD-клиент с TLS и настраиваемым таймаутом (по умолчанию 15 секунд)
  • Повторяемые пользовательские заголовки для авторизованных страниц
  • Цветная таблица результатов: 2xx — зелёный, 3xx — жёлтый, 4xx/5xx — красный
  • Экспорт результатов в CSV (разделитель ;)
  • Режим «только ошибки» (--fail) и индикатор прогресса
  • Интерфейс на русском, английском, испанском или французском языке
  • Генерация скриптов автодополнения для bash, zsh, fish и nushell
  • Адаптивный вывод под ширину терминала (POSIX ioctl / Windows API)

Установка и сборка

Из исходников

Требуется Zig 0.17.0 или новее.

git clone https://github.com/kvt/check-links.zig
cd check-links.zig
zig build

Бинарник появится в zig-out/bin/check-links.

Использование

# Проверить все ссылки на странице и вывести таблицу в терминал
check-links https://example.com/

# Показать только ошибочные ссылки
check-links --fail https://example.com/

# Увеличить таймаут и число параллельных запросов
check-links --timeout 60 --parallels 20 https://example.com/

# Экспортировать результаты в CSV-файл
check-links --export result.csv https://example.com/

Пример вывода

 №      | URL страницы            | Проверенный URL            | HTTP Код
     1. | https://example.com     | https://example.com/page1  |   200
     2. | https://example.com     | https://example.com/page2  |   200
     3. | https://example.com     | https://example.com/page3  |   302
     4. | https://example.com     | https://example.com/page4  |   404

Коды 2xx выводятся зелёным, 3xx — жёлтым, 4xx/5xx — красным.
