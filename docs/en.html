CheckLinks

A Zig CLI utility for checking links on a web page: it downloads the page, collects all links (<a href>) and images (<img src>), and verifies that every URL is reachable.

Download release GitHub repository

Features

  • Loads pages via http://, https:// and file://
  • Extracts URLs from href of <a> tags and src of <img> tags
  • Normalizes relative links and removes duplicates
  • Concurrent HEAD checks in batches (5 parallel requests by default)
  • Built-in HTTP HEAD client with TLS and a configurable timeout (15 seconds by default)
  • Repeatable custom headers for authorized pages
  • Colorized result table: 2xx — green, 3xx — yellow, 4xx/5xx — red
  • CSV export (semicolon separator)
  • Errors-only mode (--fail) and a progress bar
  • Interface in Russian, English, Spanish or French
  • Shell completion scripts for bash, zsh, fish and nushell
  • Terminal-width-aware output (POSIX ioctl / Windows API)

Installation and build

From source

Requires Zig 0.17.0 or newer.

git clone https://github.com/kvt/check-links.zig
cd check-links.zig
zig build

The binary will appear at zig-out/bin/check-links.

Prebuilt packages

Available on the Releases page:

PlatformFormat
Linux x86_64.tar.gz, .deb, .rpm
Windows x86_64.zip
macOS x86_64 / aarch64.tar.gz

Packages are built for each interface locale (ru, en, es, fr).

Usage

# Check all links on a page and print a table to the terminal
check-links https://example.com/

# Show only broken links
check-links --fail https://example.com/

# Increase the timeout and the number of parallel requests
check-links --timeout 60 --parallels 20 https://example.com/

# Export results to a CSV file
check-links --export result.csv https://example.com/

Sample output

 №      | URL                     | Checked URL                | HTTP Code
     1. | https://example.com     | https://example.com/page1  |   200
     2. | https://example.com     | https://example.com/page2  |   200
     3. | https://example.com     | https://example.com/page3  |   302
     4. | https://example.com     | https://example.com/page4  |   404

Codes 2xx are shown in green, 3xx in yellow, 4xx/5xx in red.
