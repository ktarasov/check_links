CheckLinks

Utilidad de línea de comandos en Zig para comprobar los enlaces de una página web: descarga la página, recopila todos los enlaces (<a href>) e imágenes (<img src>) y verifica la disponibilidad de cada URL.

Descargar versión Repositorio en GitHub

Características

  • Carga páginas con esquemas http://, https:// y file://
  • Extrae URLs de href en etiquetas <a> y src en <img>
  • Normaliza enlaces relativos y elimina duplicados
  • Verificación concurrente con HEAD por lotes (5 peticiones paralelas por defecto)
  • Cliente HTTP HEAD propio con TLS y timeout configurable (15 segundos por defecto)
  • Cabeceras HTTP personalizables para páginas protegidas
  • Tabla de resultados con colores: 2xx — verde, 3xx — amarillo, 4xx/5xx — rojo
  • Exportación a CSV (separador ;)
  • Modo «solo errores» (--fail) e indicador de progreso
  • Interfaz en ruso, inglés, español o francés
  • Generación de autocompletado para bash, zsh, fish y nushell
  • Salida adaptada al ancho del terminal (POSIX ioctl / Windows API)

Instalación y compilación

Desde el código fuente

Requiere Zig 0.17.0 o superior.

git clone https://github.com/kvt/check-links.zig
cd check-links.zig
zig build

El binario aparecerá en zig-out/bin/check-links.

Paquetes precompilados

Disponibles en la página de Releases:

PlataformaFormato

Los paquetes se compilan para cada idioma de la interfaz (ru, en, es, fr).

Uso

# Comprobar todos los enlaces de una página y mostrar la tabla
check-links https://example.com/

# Mostrar solo los enlaces con errores
check-links --fail https://example.com/

# Aumentar el timeout y el número de peticiones paralelas
check-links --timeout 60 --parallels 20 https://example.com/

# Exportar los resultados a un archivo CSV
check-links --export result.csv https://example.com/

Ejemplo de salida

 №      | URL                     | URL verificada             | Código HTTP
     1. | https://example.com     | https://example.com/page1  |   200
     2. | https://example.com     | https://example.com/page2  |   200
     3. | https://example.com     | https://example.com/page3  |   302
     4. | https://example.com     | https://example.com/page4  |   404

Los códigos 2xx se muestran en verde, 3xx en amarillo y 4xx/5xx en rojo.
